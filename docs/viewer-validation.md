# ビューアの検証

## 自動検証

`just check` はVite+のFormat・Lint・型検査、`just test` はモデル契約・ドラッグ判定、`just build` は配信アセット生成と本番ビルドを実行します。`just test-e2e` はChromiumのWebGLで、実モデルのホバー・個別キーの押下と復帰・ドラッグ競合・キー一覧・物理入力の切替・フォーカス喪失・視点変更・ロード失敗・モバイル幅のタッチ操作を検証します。

ブラウザテストのスクリーンショットは `test-results/`、失敗時のPlaywright traceも同ディレクトリに保存します。これらはGit管理対象外です。

2026-11-14のローカル検証では、Vite+のFormat・Lint・型検査、ユニットテスト6件、Chromium 159でのブラウザテスト9件、本番ビルド、`nix flake check --no-update-lock-file`、Nix devShellからのNode.js 24.21.0起動が通っています。ブラウザテストは1440pxのデスクトップと390pxのタッチ対応ビューポートを対象としています。

配列変更後はユニットテスト8件と本番ビルド・静的検査が通っています。既存のブラウザテスト9件に加え、刻印用Canvasへの描画内容、Backspace「⌫」・Enter「↩︎」のキー一覧表示、記号と最下段のキー入力、英数・ひらのコード通知、Tabのフォーカス移動を検証する追加テストも通っています。追加ケースはテストのクリック先を修正して単独再実行しました。更新配列の画像は `test-results/layout.png` に保存します。

キー色・ローディング修正後も、静的検査・ユニットテスト8件・本番ビルドは通過しています。モデル・照明の通信を保留し、初回表示とリロード時にローディングが表示され、描画後に終了することを確認するブラウザテストを追加しました。ただし、ブラウザ検証は描画コンテキストの中断、ブラウザ切断、タイムアウトにより完了していません。上記のブラウザテスト通過記録は、この修正前のものです。

## 配信サイズと描画方針

| 対象 | サイズ |
| --- | ---: |
| 元GLB | 1,165,376 bytes |
| 配信用GLB | 1,073,244 bytes |
| 環境HDRI（1K） | 1,686,299 bytes |

JavaScriptの本番ビルドは、アプリ部分が約234KB（gzip約73KB）、Three.js関連が約1,071KB（gzip約291KB）です。後者は500KBのチャンク警告対象であり、配信時のgzip/Brotli圧縮が必要です。

配信用GLBではキーごとのインデックスを16bitにし、未使用バッファを除去しています。現状の容量では追加のデコーダー取得が必要になるDraco・Meshopt圧縮を導入していません。GLBに埋め込まれた元の刻印画像は保持し、アプリでは配列定義に基づく共有CanvasTextureを表示します。

描画は `frameloop="demand"` で、操作・アニメーションが止まったら描画を休止します。DPRは1〜1.75に制限し、静的部品の材質、キーのテクスチャ・ジオメトリを再利用します。キーのハイライト用に材質だけ個別に複製します。動的な影は1灯、シャドウマップは2048pxです。

開発モードのPerformance APIに `keyboard-ready` マークと、操作中の `keyboard-frame` measureを記録します。後者の `detail` はdraw call数・三角形数・DPRです。休止をまたぐ150ms以上の間隔を集計から除外し、記録は約600件でリセットします。E2Eの視点変更テストでも平均フレーム間隔をログに出します。本番ビルドではフレームの計測処理を実行しません。

ローカルChrome 157の視点切替中は73サンプルで平均16.4ms、対応Chromium 159のヘッドレス実行では18サンプルで平均128.0msでした。いずれもDPR 1、shadow passを含めて113 draw calls・60,954三角形です。後者のGPU経路は特定していないため、環境間のFPS比較や実機の性能保証には使いません。DPR 1.75での実機測定、タッチ端末の負荷測定は未実施です。

## 手動検証の対象

Safari・Firefox・実際のスマートフォンのGPUやピンチ操作、長時間操作時の温度・電池消費は別途確認してください。ヘッドレスのソフトウェア描画で得たFPSは実機のGPU性能とは比較できません。実機の性能目標値は、対象端末を決めてから設定します。
